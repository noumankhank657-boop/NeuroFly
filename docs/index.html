NueroFly

A 3D arena for comparing navigation controllers in a planar fly simulation. Godot renders the world; a local Python backend handles movement, planning, and controller state.

What it shows

An editable obstacle course, A* waypoint planning, and experimental controller comparisons: synthetic LIF, direct steering, and a small connectome-wired DNa02 circuit.

How it is built

Godot 4.7 provides the 3D interface. Python 3.10+ runs the simulation and communicates with Godot over newline-delimited JSON on loopback TCP.

Connectome data

The selected MaleCNS v1.0 subgraph contains 106 nodes and 104 edges. Attribution and the stated CC-BY license are recorded in the source manifest. Its exact paper citation remains to be confirmed.

Limits

This is a deterministic planar simulation using circular obstacles and exact simulator coordinates, not vision. The DNa02 mode is a 107-neuron model with hand-set assumptions, not a complete fly brain or biological validation.

Demo highlights

  1. Start the default A* route and show the planned route and actual trajectory.
  2. Reset and change an obstacle to show replanning or a no-route case.
  3. Compare the neural modes and describe them as experiments, including their limitations.
